# Стандарты разработки 1С

Сгенерировано приложением one-s-mcp — не редактировать вручную (перезапишется).

Свод разложен по темам: открывай ту, что нужна задаче, а не всё сразу.

| Тема | Файл | Когда открывать |
|---|---|---|
| Стандартные подсистемы (БСП) | [reference/bsp.md](reference/bsp.md) | Прежде чем писать свой механизм: печать, файлы, email, права, версионирование, длительные операции, обновление ИБ |
| Шаблоны и эталоны кода (BSL) | [reference/templates.md](reference/templates.md) | Эталоны управляемых блокировок по ТЧ, контроль остатков по регистратору, аннотации расширений |
| Архитектура и принципы Senior 1C | [reference/senior.md](reference/senior.md) | Полный свод стандартов Senior-разработчика: запросы, блокировки, проведение, клиент-сервер |
| Формы, интерфейс, клиент-сервер | [reference/ui.md](reference/ui.md) | Формы и их модули, команды, оформление, серверные вызовы, распределение кода между клиентом и сервером |
| Запросы, транзакции, блокировки | [reference/data.md](reference/data.md) | Запросы и их оптимизация, чтение и запись данных, транзакции и блокировки, обмен данными |
| Код, метаданные, расширения | [reference/code.md](reference/code.md) | Оформление модулей, имена, конструкции языка, объекты метаданных, регламентные задания, расширения |
| Безопасность и права доступа | [reference/security.md](reference/security.md) | Серверный код и его вызов, внешние программы и ресурсы, пароли, роли и права, привилегированный режим |

Файла нет — значит по этой теме нет активных правил (группа выключена в приложении).

## Порядок работы
1. Открой файл темы и следуй правилам оттуда — они важнее общих знаний о платформе.
2. Правило требует механизм БСП — сначала проверь, есть ли подсистема в конфигурации
   (справочник БСП в приложении), и только потом пиши свой код.
3. Нужного правила в файле нет — ищи в полной базе знаний инструментом поиска по стандартам
   (`search_knowledge` сервера «Стандарты»): в файлы вынесены железные правила, а разборы,
   рецепты и примеры лежат в базе и достаются по запросу.
4. Сведения о конкретной конфигурации (объекты, реквизиты, методы, формы) бери ТОЛЬКО из
   приложения — поиск, граф, агент. Не по памяти и не из общих знаний.

Папки `reference/` нет вовсе — служба «База знаний» ещё не поднялась: работай через
`search_knowledge`, файлы появятся сами.
