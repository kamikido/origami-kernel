# Шаблоны и эталоны кода 1С (BSL)

## 1. Регламент версионирования изменений

Вместо `ДД.ММ.ГГГГ` подставляется текущая дата, вместо `НомерЗадачи` — номер задачи в трекере, `Фамилия И.О.` разработчика.

### 1.1. Добавление нового кода
```bsl
// { + ЛС Ширшов Д.А. НомерЗадачи, ДД.ММ.ГГГГ
// Описание изменения (при необходимости)
НоваяПеременная = 1 + Сумма;
// } ЛС Ширшов Д.А. ДД.ММ.ГГГГ
```

### 1.2. Удаление/замещение типового или чужого кода (ТАБУ на затирание)
Весь удаляемый или замещаемый чужой код **строго запрещено затирать**.
В удаляемый код в начале каждой строки ставится двойной слэш `//`, чтобы было наглядно видно, что именно удалено и что добавлено:
```bsl
// { - ЛС Ширшов Д.А. НомерЗадачи, ДД.ММ.ГГГГ
// Переменная = 1 + 3;
// } ЛС Ширшов Д.А. ДД.ММ.ГГГГ
// { + ЛС Ширшов Д.А. НомерЗадачи, ДД.ММ.ГГГГ
// Описание изменения (при необходимости)
Переменная = 1 + Сумма;
// } ЛС Ширшов Д.А. ДД.ММ.ГГГГ
```

### 1.3. Расположение меток
Метки изменений ставятся **строго внутри** тел процедур и функций, оборачивая непосредственно изменяемый блок кода (не над заголовком процедуры).

## 3. Расширения конфигурации

### 3.1. &Вместо (обязателен ПродолжитьВызов, если логика не вытесняется полностью)
```bsl
&Вместо("РассчитатьСкидку")
Функция Расш_РассчитатьСкидкуВместо(ПараметрыРасчета)
	Результат = ПродолжитьВызов(ПараметрыРасчета);
	Возврат Результат;
КонецФункции
```

### 3.2. &ИзменениеИКонтроль
```bsl
&ИзменениеИКонтроль("ЗаполнитьРеквизиты")
Процедура Расш_ЗаполнитьРеквизиты()
	#Вставка
	// + ЛС Фамилия И.О. НомерЗадачи, ДД.ММ.ГГГГ
	Если Не ЗначениеЗаполнено(Организация) Тогда
		Организация = ОсновнаяОрганизация();
	КонецЕсли;
	// - ЛС Фамилия И.О. ДД.ММ.ГГГГ
	#КонецВставки
	#Удаление
	СтараяПроцедура();
	#КонецУдаления
КонецПроцедуры
```

## 4. Эталоны критических BSL-конструкций

### 4.1. Управляемая блокировка по ТЧ документа
```bsl
ТаблицаБлокировки = Товары.Выгрузить();
ТаблицаБлокировки.Свернуть("Склад, Номенклатура");

Блокировка = Новый БлокировкаДанных;
Элемент = Блокировка.Добавить("РегистрНакопления.ОстаткиНоменклатуры");
Элемент.Режим = РежимБлокировкиДанных.Исключительный;
Элемент.УстановитьЗначение("Организация", Организация);
Элемент.ИсточникДанных = ТаблицаБлокировки;
Элемент.ИспользоватьИзИсточникаДанных("Склад", "Склад");
Элемент.ИспользоватьИзИсточникаДанных("Номенклатура", "Номенклатура");
Блокировка.Заблокировать();
```

### 4.2. Сбор всех ошибок ТЧ без раннего Возврат
```bsl
Для Каждого СтрТЧ Из ТаблицаОшибок Цикл
	Отказ = Истина;
	Текст = СтрШаблон(НСтр("ru = 'По строке %1 не заполнен %2'"), СтрТЧ.НомерСтроки, СтрТЧ.Номенклатура);
	Поле = СтрШаблон("Объект.Товары[%1].Номенклатура", СтрТЧ.НомерСтроки - 1);
	ОбщегоНазначенияКлиентСервер.СообщитьПользователю(Текст, ЭтотОбъект, Поле, "Объект");
КонецЦикла;

Если Отказ Тогда
	Возврат; // Выход строго ПОСЛЕ обхода всех строк!
КонецЕсли;
```

### 4.3. Новая методика контроля остатков (по регистратору)
```bsl
// 1. Формирование и запись движений
Движения.ОстаткиНоменклатуры.Записывать = Истина;
// ... заполнение движений ...
Движения.Записать();

// 2. Проверка остатков запросом по регистратору текущего документа
Запрос = Новый Запрос;
Запрос.Текст = 
	"ВЫБРАТЬ
	|	Остатки.Склад, Остатки.Номенклатура, -Остатки.КоличествоОстаток КАК Нехватка
	|ИЗ
	|	РегистрНакопления.ОстаткиНоменклатуры.Остатки(&ГраницаВключая,
	|		(Организация, Склад, Номенклатура) В
	|			(ВЫБРАТЬ Дв.Организация, Дв.Склад, Дв.Номенклатура
	|			 ИЗ РегистрНакопления.ОстаткиНоменклатуры КАК Дв
	|			 ГДЕ Дв.Регистратор = &Ссылка)) КАК Остатки
	|ГДЕ Остатки.КоличествоОстаток < 0";

Запрос.УстановитьПараметр("ГраницаВключая", Новый Граница(МоментВремени(), ВидГраницы.Включая));
Запрос.УстановитьПараметр("Ссылка", Ссылка);
Выборка = Запрос.Выполнить().Выбрать();
Пока Выборка.Следующий() Цикл
	Отказ = Истина;
	ОбщегоНазначенияКлиентСервер.СообщитьПользователю(
		СтрШаблон(НСтр("ru = 'Недостаточно товара %1 на складе %2 (нехватка: %3)'"),
			Выборка.Номенклатура, Выборка.Склад, Выборка.Нехватка));
КонецЦикла;
```
