# Работа по 1С в этом проекте

Сгенерировано приложением one-s-mcp — не редактировать вручную (перезапишется).

Этот проект — про 1С:Предприятие. Задача про код, запросы, формы, метаданные, отчёты и
обработки, расширения, производительность или разбор чужого кода — это задача по 1С, даже
если слово «1С» в ней не названо: «переписать медленный запрос», «объясни, что делает эта
процедура», «почему форма долго открывается» — про 1С.

ПЕРВОЕ действие в такой задаче — вызвать скилл `1c-standards`. Не отвечать по существу и не
задавать уточняющих вопросов до этого вызова: там свод правил платформы и перечень подсистем
БСП, без которых ответ будет неверным. Затем вызвать скилл `one-s-mcp` — чем разведать
конфигурацию и какой инструмент под что.

Задача вне платформы (администрирование ОС, сторонние сервисы и языки, общие вопросы) решается
обычным порядком — скиллы для неё не нужны.

Сведения о конкретной конфигурации (объекты, реквизиты, методы, формы) бери ТОЛЬКО из
приложения — поиск, граф, агент. Не по памяти и не из общих знаний.
