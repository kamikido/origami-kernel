# Плейбуки one-s-mcp: порядок под типовые задачи

Открывается по требованию из скилла one-s-mcp, когда взялся за соответствующую задачу.

## Сделать обработку/отчёт
1. Разведка: какие объекты/реквизиты/регистры реально есть — поиском по конфигурации и графом. Не
   выдумывай имена.
2. Стандарты: найди поиском по стандартам правила под задачу (периоды, длительные операции, печать,
   показ строк с неопределёнными данными).
3. Сборка по найденным фактам и стандартам. Имена, префикс и размещение новых объектов — по
   политике «Настройки и параметры» из SKILL.md: фолбэки с образцов конфигурации, без вопросов
   пользователю; исключение — «основная или расширение», если не выводится из фактов.
4. Проверка синтаксиса BSL после правок.
5. Для внешней обработки — пройди чек-лист сдачи из стандартов (поиск по стандартам).

## Доработать форму
1. Не трогай существующие элементы формы: новые встраивай, существующие не меняй/не удаляй без явного
   указания пользователя.
2. Смотри структуру формы через сервер форм / граф, прежде чем менять.
3. Подключаемые команды/печать/длительные операции — через БСП (справочник БСП), не вручную.

## Программная запись/проведение документа
1. Перед программным изменением — Заблокировать().
2. Проведение — в неоперативном режиме.
3. Точные сигнатуры и правила — поиском по стандартам и в справочнике БСП.

## Анализ влияния изменения
1. Граф конфигурации: цепочки вызовов и обратные зависимости объекта.
2. Поиск использований объекта — прежде чем менять.
3. Сложное — отдай агенту (он соберёт картину по службам).
