# Каталог архитектурных плейбуков Origami Kernel (Долговременная память)

> **Концепция Долговременной памяти:**  
> В отличие от кратковременных правил IDE (`AGENTS.md`, `1c-protocol.md`), которые постоянно загружаются в системный промпт модели и ограничены бюджетом в 20 000 токенов, **плейбуки лежат на диске и не расходуют токены системного контекста (0 токенов в фоне)**.  
> Агент и разработчик обращаются к ним точечно через CLI `origami playbook` или `read_file` строго при возникновении профильной задачи.

## Как обмениваться знаниями между командами и проектами

Плейбуки разработаны как **отчуждаемые единицы архитектурного опыта**:
1. **Передача знаний в другой проект:** скопируйте любой файл `.md` из этой папки в папку `knowledge/playbooks/` другого проекта.
2. **Проверка доступных стандартов:**
   ```powershell
   .\tools\origami.ps1 playbook list
   ```
3. **Поиск стандарта по ключевому слову:**
   ```powershell
   .\tools\origami.ps1 playbook find ущерб
   ```
4. **Чтение стандарта:**
   ```powershell
   .\tools\origami.ps1 playbook read pb_damage_accounting_registers
   ```

## Как создать новый плейбук из совещания

Для извлечения новых стандартов из стенограмм встреч используется модуль обратной связи:
```powershell
.\tools\origami.ps1 feedback -m "путь/к/стенограмме.txt" [-t 1234]
```
Скрипт анализирует стенограмму через локальный OmniRoute, выявляет слепые зоны и генерирует готовый обезличенный плейбук `knowledge/playbooks/pb_<тема>.md`.
